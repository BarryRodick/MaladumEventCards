# Event Deck Companion

[**Open Event Deck → eventdeck.rodick.me**](https://eventdeck.rodick.me/)

A companion for playing Maladum, built to make managing your event deck easier at the table.

## What it does

- Build a deck from your chosen content sets and difficulty.
- Draw cards, go back, manage card actions and track ongoing effects.
- Save games and pick them up later.
- Use the Crafting Workshop.
- Include optional House Ruled Additions, including Battle Systems - Hard Mode.
- Create your own card collections and optionally add them to a deck.
- Add the app to your phone’s home screen.

## Bugs, ideas and feedback

This repository is the home for Event Deck feedback and issue tracking.

- [Report a bug or suggest an improvement](https://github.com/BarryRodick/MaladumEventCards/issues/new)
- [Browse existing issues and feedback](https://github.com/BarryRodick/MaladumEventCards/issues)

Please check existing issues before posting. For a bug, include what happened, how to reproduce it, and your device and browser. Screenshots are welcome. GitHub submissions are public and require a GitHub account.

## Where the app lives

The app is hosted separately at **https://eventdeck.rodick.me/**. This repository contains its introduction and feedback tracker; it does not contain the current app’s source or deployment.

The previous hosted address, [eventdeck.barryrodick.chatgpt.site](https://eventdeck.barryrodick.chatgpt.site/companion/), remains available for existing browser saves. Browser-local saves belong to the browser and address where they were created.

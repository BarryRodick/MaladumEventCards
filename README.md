# Event Deck Companion

[Open Event Deck](https://eventdeck.rodick.me/) · [Report a bug or suggest an improvement](https://github.com/BarryRodick/MaladumEventCards/issues/new) · [View feedback](https://github.com/BarryRodick/MaladumEventCards/issues)

Build and run Maladum event decks, track ongoing effects, save games and use the Crafting Workshop. Optional House Ruled Additions include Battle Systems - Hard Mode and your own custom card collections.

## Feedback

Use this repository’s Issues for bugs, card corrections and ideas about the current hosted app. Check existing issues first. For a bug, include what happened, steps to reproduce, expected behavior and your device/browser. Submissions are public and require a GitHub account.

## Hosting and source

The current app runs at **https://eventdeck.rodick.me/** on ChatGPT Sites. Its deployed source is maintained through the existing Sites project, separately from the legacy runtime in this repository. Changes to this repository do not automatically update the current companion.

The [previous Sites address](https://eventdeck.barryrodick.chatgpt.site/companion/) remains available for saves held in that browser origin. Device saves are specific to the browser and address; moving between URLs does not transfer them automatically.

## Legacy application

GitHub Pages redirects to the current app. The [legacy app](https://barryrodick.github.io/MaladumEventCards/?legacy=1) remains available for existing local decks and campaigns. Its code, assets, catalog and tests are retained here to preserve that access.

Older runtime, storage, campaign and development instructions are archived in [the legacy guide](docs/legacy/README.md). They describe the legacy app, not the current hosted companion.
